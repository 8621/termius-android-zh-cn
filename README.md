# Termius Android 简体中文本地化研究

非官方社区项目，与 Termius 官方及其开发商无关联。

## 项目状态

- 目标应用：Termius Android 7.11.1 (987)
- 汉化候选：新增翻译资源键 1,841 个（不等于可见界面翻译率）
- 适配测试：ARM64 / Android 8.0+ 的一台 OnePlus Ace 5 实机
- 实机已验证：中文界面、SSH 登录、SFTP 浏览、小文件上传下载，以及允许后台活动后的切换稳定性
- 未验证：所有 Android 设备兼容性、全部账户登录/云服务、订阅、推送等

## 当前公开范围

当前仓库仅提供项目说明、测试记录与安全/贡献指南。完整构建工程、实际翻译表仍需进行逐文件版权和敏感信息检查，**尚未发布**。请勿将此仓库理解为已提供可一键构建的汉化工程。
